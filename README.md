## 무엇을 만드는 사람인가

> **시장 데이터를 수집·검증해 의사결정으로 바꾸는 백엔드**, 그리고 **그 과정을 자동화하는 LLM 파이프라인**을 만듭니다.

- 📈 **금융 데이터 파이프라인** — 거래소 public API 수집 → 로컬 DB 적재 → 백테스트까지 CLI 하나로
- 🤖 **LLM 애플리케이션** — RAG·근거 인용·에이전트 워크플로우를 실제로 굴러가는 서비스로
- ⚙️ **자동화** — 매일 돌아가는 파이프라인이 스스로 콘텐츠를 발행하고 커밋하게

## 매일 돌리는 것

공부를 이벤트가 아니라 **파이프라인**으로 만들었습니다. 8개 학습 팩(코딩테스트 · CS 개념 · 코드 리딩 · DB 설계 · 백엔드 · 데이터사이언스 · 시스템 디자인 · 영어)이 매일 카드 한 장씩 자동 발행되고, 읽고 자기설명을 쓰면 그날 커밋이 남습니다. 검증된 개념만 개인 지식 베이스로 승격됩니다.

```

```
